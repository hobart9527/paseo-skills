# Rulings

Accepted, non-obvious decisions made while the contract was being reviewed. One
entry per decision: what was ambiguous, what was decided, and why. This file is
not part of the contract — `freeze-check` exempts it (and `review.md`) from R0
drift, so recording a ruling never voids the sign-off.

Format:

```
## <short title>
- Decided: <the rule the pipeline will follow>
- Why: <evidence or constraint that forced it>
- Scope: <which tasks / files it covers>
```
